> 学习目标：掌握 Kotlin 变量、函数、控制流、空安全、集合、字符串，能对照 Java 写出 idiomatic Kotlin。
> 学习方式：读概念 → 对照 Java → 看示例 → 完成「验证点」代码题 → 交给我 review。

## 1.1 变量与类型

### 概念讲解

Kotlin 的变量分两种：`val`（只读，类似 Java `final`）和 `var`（可变）。声明时类型可省略，编译器自动推断。

基础类型（Int/Long/Double/Float/Boolean/Char）在源码里是「类」，但编译后仍映射到 JVM 原始类型，性能与 Java 一致。**关键差异**：Kotlin 的「可空类型」与「非空类型」是两种不同类型（`Int?` ≠ `Int`），这是空安全的根基。

类型转换：Kotlin **不做隐式数值转换**（Java 的 `int → long` 自动提升，在 Kotlin 里必须显式 `toLong()`）。

### 对照 Java

| Kotlin | Java | 说明 |
|--------|------|------|
| `val x = 1` | `final int x = 1` | 只读 |
| `var x = 1` | `int x = 1` | 可变 |
| `val s: String = "a"` | `String s = "a"` | 显式类型 |
| `Int` | `int` / `Integer` | 基础类型是类，编译后优化 |
| `Int?` | `Integer`（可空） | 可空类型 |
| `Any` | `Object` | 所有类父类 |
| `Unit` | `void` | 但 Unit 是真实类型 |
| `Nothing` | 无对应 | 永不返回（抛异常/死循环） |
| `1.toLong()` | `1L` / `(long) 1` | 无隐式转换 |

### 示例代码

```kotlin
// 类型推断
val name = "Tom"          // String
var age = 38              // Int
val price = 3.14          // Double

// 显式类型 + 后缀
val id: Long = 100L

// 可空类型 vs 非空类型
val nullable: String? = null      // 可空，能赋 null
val notNull: String = "x"         // 非空，赋 null 编译报错

// 类型转换：Kotlin 不做隐式数值转换
val a: Int = 10
val b: Long = a.toLong()          // 必须显式
val c: String = 3.14.toString()

// 智能转换（smart cast）
fun printLen(obj: Any) {
    if (obj is String) {
        println(obj.length)       // 这里 obj 已自动转成 String
    }
}
```

### 验证点（你动手写）

1. 用 `val` 声明一个 `String` 和 `Int`，用 `var` 声明一个 `Double`，再尝试给 `val` 重新赋值（体会编译错误）
2. 声明一个 `String?` 赋 `null`，用 `?.` 安全调用 `.length`（结果应为 null），再用 `?:` 给默认值 0
3. 把 `Int` 转 `Long`、`Double` 转 `String`（体会「无隐式转换」）
4. 写函数 `fun describe(x: Any)`，用 `is String` / `is Int` 智能转换后分别打印
