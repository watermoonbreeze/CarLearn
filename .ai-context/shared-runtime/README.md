# 共享运行资料区

1. 本目录是 Claude/Codex 共用的**可移植、非敏感、格式中立**运行资料区。
2. 可按需建立 `handoffs/`、`cache/`、`exports/`、`plugin-sources/`、`config/`；每个文件标注来源、生成时间、可再生成性。
3. **严禁迁入**：认证/token/cookie/API Key/私钥/证书、真实环境文件、原始会话、SQLite、历史、工具缓存、遥测、插件安装状态、锁文件。外部服务密钥仅由环境变量/系统凭据库/获准密钥管理服务提供。
4. 本目录是项目级，只存本项目资料；长期规则/能力写入 `.ai-context/` 对应规范目录，正式项目文档写入 `docs/`，不混放。
